## Tunegrab 1.0.0 — first release 🎵

Paste YouTube links, press **Download MP3**, get clean MP3 files with title, artist and cover art.

**Download:** `Tunegrab.exe` below (Windows 10/11, 64-bit). No installation needed.

### What's inside
- Playlists and many links at once
- 320 / 192 / 128 kbps
- Title, artist and cover art in every file
- Picks links up from the clipboard automatically
- Self-updating download engine (yt-dlp), checksum-verified
- 11 languages, light and dark mode

### First launch
- Windows may show **"Windows protected your PC"**. Click **More info → Run anyway** (the app is not code-signed yet).
- The first launch downloads the download engine (~65 MB) once.

Only download content you have the right to.
