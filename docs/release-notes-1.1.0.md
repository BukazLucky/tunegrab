## Tunegrab 1.1.0 — MP3 button in your browser 🎵

### New
- **Browser extension "Tunegrab: MP3 button"**: an MP3 button next to Like on every YouTube video (floating on Shorts
  and playlists), plus a right-click menu item and a toolbar icon. One click, and Tunegrab starts downloading.
- **Links from the browser go straight to the open window**: no second window, the download starts by itself
  (or right after the current one finishes).

### Downloads
- `Tunegrab.exe`: the Windows app (open it once after updating, so the browser button knows where it is).
- `tunegrab-extension-chromium-1.1.0.zip`: extension for Chrome, Edge, Opera, Yandex and Brave.
  How to install: see the README, section "MP3 button in your browser".
- `tunegrab-extension-firefox-1.1.0.zip`: extension package for Firefox.

The extension collects no data ([privacy](https://github.com/BukazLucky/tunegrab/blob/main/PRIVACY.md)).
Only download content you have the right to.
